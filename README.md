## ⚡ Features & Highlights

- **Interactive Dev Terminal**: Recruiter-friendly embedded terminal dock supporting commands (`whoami`, `projects --featured`, `cat skills.json`, `experience`, `certifications`, `contact`).
- **Featured Systems**:
  - **Flux**: Enterprise Agile Workspace & Cloud Engine (React 19, AWS S3 presigned URLs, Polyglot DB, DFS deadlock detection, DORA metrics).
  - **TaskGenie**: Service Marketplace with PostgreSQL spatial indexing (-80% query latency) & Razorpay Webhooks.
  - **CineBuzz**: Movie & Media discovery platform.
  - **Companion**: AI-powered senior care assistant (Flutter & BERT).
- **Experience & Leadership Timeline**: GeekyAnts Software Engineer Internship deliverables & GDG Core Technical Member leadership.
- **Categorized Technical Matrix**: Filterable skills across Languages, Frontend, Backend, Databases, Cloud & DevOps, and Core CS.
- **Performance**: 60fps buttery-smooth interactions built with Framer Motion, GSAP, and Tailwind CSS.

## 🚀 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/sanskriti49/sanskriti-portfolio.git

# Navigate into the project directory
cd sanskriti-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

# Create a production build
npm run build
```
